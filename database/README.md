# TechFix local mobile catalogue

`mobile-catalog.csv` is a local import of the public **Global Smartphone Database 2025** dataset by Rajib Dab (Kaggle: `rajibdab/global-smartphone-database-2025`), downloaded on 2026-08-10. It is loaded locally at runtime; no device data is fetched from third-party sites by visitors.

The importer keeps TechFix's original records authoritative and only adds non-duplicate records. Empty source fields remain empty. Review and update this CSV with its source/license terms before commercial redistribution.
